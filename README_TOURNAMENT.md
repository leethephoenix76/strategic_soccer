# Турнир ботов на сервере (08.11.2026)

Круговой турнир 8 ботов: каждая пара играет обоими цветами на каждом seed; эпизод — 22 командных полухода от начального удара 0:0, 120 с на полуход, один поток на бота, одновременно по эпизоду на физическое ядро (минус одно).

| имя | бот | зачем |
|---|---|---|
| pkr | `goal-sel-run-geo-cover-timed-rbr-ext2w-pkr-b8-t120` | бот по умолчанию |
| pv10 | `…-pkr-pv10-b8-t120` | ценность владения W = 0,1 |
| pv20 | `…-pkr-pv-b8-t120` | W = 0,2 |
| pv30 | `…-pkr-pv30-b8-t120` | W = 0,3 |
| bf | `…-pkr-bf-b8-t120` | «мяч сначала» во внутренних узлах |
| mo | `…-pkr-mo-b8-t120` | пас и отбор только по главному исходу |
| ext2w | `goal-sel-run-geo-cover-timed-rbr-ext2w-b8-t120` | бот по умолчанию 01.11–02.11 |
| fb | `goal-sel-run-fb-b8-t120` | старый бот, нижняя отметка |

4 seed (7, 19, 31, 43) → 28 пар × 2 цвета × 4 = 224 эпизода. Порядок — по seed: после первых 56 эпизодов круг уже полный, каждый следующий seed его удваивает. При 34 эпизодах одновременно — не больше ~5 ч (каждый эпизод ≤ 44 мин).

## Запуск

```bash
tar xzf soccer_tournament_20261108.tgz && cd soccer_tournament_20261108
./run_tournament.sh smoke                                   # сборка, тесты движка, проверка цепочки (~1 мин)
nohup ./run_tournament.sh run > tournament.log 2>&1 &       # турнир; в конце — архив результатов
tail -f tournament.log                                      # строка на каждый законченный эпизод: белые_vs_чёрные, счёт, xG
./run_tournament.sh status                                  # таблица на текущий момент (можно во время игры)
```

Варианты (передаются после `run`): `--seeds 7,19` (меньше времени, ~2,5 ч), `--jobs 30`, `--time 90|180|300`. Если прервалось — тот же `run` ещё раз: законченные эпизоды пропускаются, незаконченные играются заново. Архив вручную — `./run_tournament.sh pack`.

## Где смотреть

Папка `tournament/` (её же содержит архив `soccer_tournament_<host>_<дата>.tgz`):

- `report/standings.txt` — **итоговая таблица**: эпизоды, В-Н-П, очки (3/1/0) и очки за эпизод, голы, xG свой/чужой за эпизод, **разница xG за эпизод ± стандартная ошибка** (главный показатель: голов мало), удары, пасы, ходы с мячом, потери мяча в игре;
- `report/pairs.txt` — бот × бот: очки за эпизод, средняя разница xG, счёт по голам;
- `report/games.csv` — строка на эпизод (статистика обеих сторон);
- `report/stats_all.txt` — `ssbot stats` по всем записям (сводка по игрокам);
- `games/<белые>_vs_<чёрные>_s<seed>.ssn` — записи партий (открываются в `soccer.exe`), `.csv` — трасса поиска, `.log` — вывод;
- `settings.txt`, `bots.txt` — условия и список ботов этой копии `ssbot`;
- `tournament.log` (рядом с папкой) — ход турнира: на каждый эпизод счёт (белые:чёрные) и xG, в конце — обе таблицы.

Для сравнения W смотреть строки pv10/pv20/pv30 против pkr в `pairs.txt` и столбцы «ball» (ходы с мячом) и «lost» в `standings.txt`.

Привезти архив в `build/server_<дата>/`.

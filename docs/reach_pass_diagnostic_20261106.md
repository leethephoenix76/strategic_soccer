# Пасы и карта раздувания — диагностика 06.11.2026

Источник: десять начальных позиций `tests/bot_suite_cases_v4.json`.
Повторить набор: `powershell -File tools/run_reach_pass_probe.ps1`.
Команда `ssbot reach-pass "<position>"` строит одну карту `ComputeReachFront`, затем
перебирает законные пасы из исходной расстановки. Для каждого паса она
перечисляет исходы первого отрезка по правилам и запускает `SolveBallRace`
только для исхода `BallThrough`. Клетки пути мяча берутся из окон решателя:
карта проверяется в момент прибытия мяча и в следующие доступные полуходы.
Полные данные: `build/reach_pass_v4_20261106.csv`.

На ветке без касания все 249 пасов с первой встречей своего фронта решатель
пометил как `Taken` своей командой; все 78 с первой встречей чужого фронта —
как `Taken` соперником. Среди 252 без встречи на пути: 214 рестартов, 37
прямых передач в занятую клетку и один спорный исход. Если отбрасывать 78
пасов по фронту, на этом наборе не теряется ни один гарантированный приём
своей командой **в ветке `BallThrough`**. Это лишь оценка возможного числа
пропущенных подробных проверок в исходном состоянии (13,5% от 579 пасов),
не замер экономии поиска.

Первый отрезок не детерминирован. Среди 78 пасов с чужой встречей средние
вероятности: мяч прошёл 0,789, свой перехват 0,017, перехват соперника 0,068,
рикошет 0,126. Значит, даже эта группа не имеет сертификата проигрыша.
Сравнение по одной клетке **назначения** ошибочно отбросило бы 23 паса с
доказанным подбором своей командой дальше на пути. После движения игроков
внутри хода карта исходной расстановки также не описывает новое состояние.

`map_ms` в CSV — 20–40 мс в каждом отдельном процессе и включает построение
общей таблицы переходов при первом вызове. Сумма `race_ms` для всех 579
проверок в последнем прогоне — 46,8 мс; эти вызовы вынесены из времени карты.
`target` и `path_cell` записаны в игровой нотации (`docs/notation.md`).
Тёплая стоимость C++ карты на узлах поиска ещё не измерена. Набор содержит
три защитные позиции без законного паса; он не проверяет решение после
перемещений, ближайший ответ соперника и продолжение до удара.

Решение для первого опытного бота: использовать прогноз своего приёма как
отдельную категорию паса в пространство среди кандидатов корня, без
жёсткого отсечения и без изменения оценки листа или вероятностных исходов.
Сравнение качества — те же v4 при ширине 8 и лимитах 90/180 с на полуход.

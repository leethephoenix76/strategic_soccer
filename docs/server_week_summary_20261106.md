# Итоги серверной недели (02–06.11.2026) и план

Сервер: EPYC 7763, 35 физических / 40 логических ядер. Разборы — `server_results_20261103.md`, `server_results_w3_20261104.md`, `server_results_node_20261104.md`, `server_results_ref_20261106.md`.

## Что узнали

1. **Мощность.** Один поиск на потоках — потолок ×3–4,5 к 16 потокам (распараллелены только оценки внутри узла); 35 независимых поисков — ×29. Удвоение времени — +0,3 хода команды (≈ +1,4 действия; цена хода команды ~×11, жёсткий луч без сокращений).
2. **Статика против перебора** (600 позиций): порядок позиций статика держит (ранговая корреляция 0,9), но недооценивает команду, которая владеет мячом и ходит, на 0,06–0,14 (d5 ~0,2), растёт с глубиной; связано с пасом на ход. Чётность: V(d+1) − V(d) чередуется ±0,04 — право хода не учтено.
3. **Горизонт.** В листьях главной линии статика переоценивает сторону корня на ~0,1 (80% линий); две трети листьев — свободный мяч после паса при ходе соперника.
4. **Внутренний узел беднее корня** (теряет 0,015–0,03 в среднем, > 0,05 у 17% позиций; не видит «сначала мяч», например `>g8` в g2_148w) — половина асимметрии корня (0,04–0,17).
5. **Эталон лучом не сходится**: порядок кандидатов меняется с чётностью горизонта и шириной; метод смещён в пользу кандидатов с пасом внутри хода. Для эпизодов эталон — точный перебор по участникам.
6. Инструменты: детерминированный параллельный перебор, `run_server.sh` с продолжением после обрыва, `consistency`, `reference`, `--root-as-node`, `--outcome`, распределение ядер по стоимости.

## План (по порядку, каждый шаг — изменение алгоритма, проверка на сервере теми же замерами)

1. **Внутренний узел как корень**: решения по категориям мяча (держать, удар, пас каждому партнёру, подбор) и «сначала мяч, потом перемещения». Проверка: асимметрия корня (лестница из позиции / после хода), потеря внутреннего узла, горизонт.
2. **Свободный мяч в листе**: тихий поиск по мячу (продлевать линию, пока мяч свободен) или ход соперника по мячу в оценке листа. Проверка: горизонт (переоценка в листьях → 0).
3. **Ценность владения с правом хода в статике** (пас на ход, на несколько ходов — «мяч — ферзь», маршруты мяча). Проверка: смещение по классам и чётность в `consistency`.
4. **Цена глубины**: сокращения по рангу в луче (переменная глубина); затем параллельные поддеревья (детерминированно, окно от первой ветви). Проверка: кривые «глубина от времени», масштабирование.
5. **Эталон**: кандидаты в одной точке (после конца хода), уровни одной чётности; эпизоды — точный перебор.

После каждого шага: тесты, `consistency` (≈6 ч на сервере), матч против `-pkr-` у пользователя.

# Опытный бот с картой раздувания — 06.11.2026

Вариант `goal-sel-run-geo-cover-timed-rbr-ext2w-pkr-wave-b8-t…`
отличается от `-pkr-` одним механизмом: пас в пустую клетку, на пути которого
карта первой встречает своего игрока, получает отдельный вид решения в
корневом луче ширины 8. Карта строится один раз на начальную позицию хода;
окна времени мяча даёт `SolveBallRace` после `BallThrough`. Внутренние узлы,
пасы после перемещений, листовая оценка, минимакс и все исходы паса прежние.
Вариант `unproven`; бот по умолчанию не менялся.

Диагностика фильтра до этого изменения —
[reach_pass_diagnostic_20261106.md](reach_pass_diagnostic_20261106.md).
Команды прогона — `tools/run_reach_wave_suite.ps1` и
`tools/summarize_reach_wave_suite.ps1`. Исходные позиции —
`tests/bot_suite_cases_v4.json`. Сырые результаты и таблица —
`build/wave_pass_suite_20261106/` (`summary.csv`): по одному процессу на
поиск, ширина 8, 90 и 180 секунд на командный полуход для обоих ботов,
40 завершённых запусков, внешних тайм-аутов 0. Первый запуск
`g7_38b_shot` на 90 с аномально занял 3838,9 с; он сохранён как
`*.overrun`, затем повторён под внешним ограничением и в таблицу не входит.

Числа в скобках — завершённая глубина `-pkr-` / `-wave-` либо общая
глубина. В `g7_03w_control` позиция после базового хода имеет листовую
оценку после EndTurn +0,2321, после опытного +0,1955. Поиск ближайшего
ответа чёрных одним полным ходом (`--turn-depth 1 --time 5`) дал
соответственно `2h11 3c13 end`, +0,1800 и `3d13 1g12 end`, +0,1147.
По этой локальной проверке новая расстановка слабее, хотя собственный
углублённый поиск опытного бота оценил её выше.

В Longpass (`148.W`, ход 74, белые) базовый бот после случайно не задетого
`>g8` продолжает ход `2i6 3g2 1j11 end`; решатель гонки затем гарантирует
подбор W1 на g17 в слоте 5. Опытный бот уже переместил всех до `>g7`;
после `end` W1 гарантированно берёт мяч на g11 в слоте 1. Обе линии сохраняют
мяч, но базовая ведёт W1 ближе к воротам. Ближайший ответ чёрных одним
полным ходом: на базовой линии `2k11 end`, оценка белых +0,6111;
на опытной `3e7 2j11 end`, +0,0568. Это селективная проверка, не точный
эталон, но она подтверждает устойчивую разницу качества выхода при 90/180 с.

**Вывод.** Отдельный вид «первый приём своей областью» слишком широк:
представитель категории вытесняет другие пасы в пространство, хотя разные
маршруты приводят к разной позиции W1 после подбора. Улучшения на всём v4
нет; вариант остаётся опытным и не рекомендуется для игры по умолчанию.
Следующий опыт должен сохранять разнообразие *маршрутов и точки приёма*
внутри категории либо использовать карту только для порядка проверки,
не заменяя уже выбранные базовым лучом решения. Сначала сравнить такие
альтернативы на Longpass и спокойной атаке, затем снова на всём v4.

Отчёт поиска даёт числа отброшенных перемещений и действий для каждого
запуска в `summary.csv`, но не содержит общего числа кандидатов; точную
долю отброшенных продолжений из него вычислить нельзя. Фиксированное время
также допускает разные завершённые глубины, как на `g9_17w_b5_fixed`
при 90 с без использования карты.

# Нотация Strategic Soccer (SSN)

Oct 15, 2026 · @valery

Текстовая запись клеток, действий, случайных исходов, позиций и целых партий — аналог шахматной алгебраической нотации, FEN и PGN. Реализация — `src/engine/notation.h/.cpp`, проверка — `tests/engine_tests.cpp` (`TestNotation`, `TestGameRecord`).

## Клетки

Вертикали `a`…`k` — x = 0…10 слева направо. Горизонтали считаются от линии ворот White, как в шахматах: **горизонталь = 20 − y**.

| | Горизонталь | y |
| --- | --- | --- |
| Линия ворот White (низ экрана) | 0 | 20 |
| Поле | 1…19 | 19…1 |
| Линия ворот Black (верх экрана) | 20 | 0 |

White играет «вверх», к горизонтали 20. Центр (5, 10) — **f10**. Створ ворот Black — e19, f19, g19 (y = 1); створ ворот White — e1, f1, g1 (y = 19). Стартовые позиции: White — a6…a9, Black — k11…k14.

## Игроки

Внутри хода игроки своей команды обозначаются цифрами **1–4**. В исходах и позициях, где нужна команда, — **W1…W4** (номера 0–3 в движке) и **B1…B4** (номера 4–7).

## Действия

| Запись | Действие |
| --- | --- |
| `3f12` | игрок 3 идёт на f12 (при расстановке — ставится на f12) |
| `2x` | игрок 2 атакует (отбор или выковыривание — определяется позицией) |
| `>h15` | владелец мяча пасует в h15 |
| `#` | владелец мяча бьёт по воротам |
| конец строки | End Turn |
| `--` | ход без действий (сразу End Turn) |

## Случайные исходы

Исход записывается в фигурных скобках сразу после действия:

| Действие | Исход | Запись |
| --- | --- | --- |
| пас | мяч прошёл | `{ok}` |
| | перехват игроком | `{int B2}` |
| | рикошет от игрока в клетку | `{defl W3 e7}` |
| атака | мяч отобран / выковырян | `{won}` |
| | мяч выбит в клетку | `{loose e7}` |
| | мяч остался | `{kept}` |
| удар | гол | `{goal}` |
| | вратарь поймал | `{caught}` |
| | вратарь отбил в клетку | `{parried f17}` |

Шаг свободного мяча на End Turn тоже случаен, если на его пути есть игроки. Его исход пишется в конце строки после черты: `... 4c19 | {int W2}`.

Если мяч после выбранного исхода выходит за поле, запись дополняется комментарием `; ball out by W, B restarts` (либо наоборот). Аут не является отдельным случайным исходом: он определяется скоростью мяча и исходом `BallThrough`.

Исходы записываются только у действий, где возможно больше одного исхода. При чтении исход можно опустить — тогда он разыгрывается генератором (тег `Seed`).

## Позиция

Позиция в игре (аналог FEN) — одна строка из полей через пробел; на начало хода — только основные поля, внутри хода — ещё необязательные (ниже):

```
<w|b> <полуходы> <счёт W>-<счёт B> <W1> <W2> <W3> <W4> <B1> <B2> <B3> <B4> <мяч> [t:<W|B>[p]] [a:<W|B>] [m:…] [x:…] [f:…] [l:…] [s:…]
```

| Поле | Смысл |
| --- | --- |
| `w` / `b` | чей ход |
| полуходы | `halfTurns` (время = полуходы / 2 минут) |
| игрок | `f10` — стоит; `f10/f11` — сейчас на f10, ходом раньше был на f11 (это задаёт инерцию) |
| мяч | `@W2` — у игрока; `@e7` — свободный, лежит; `@e7,+1,-2,1` — катится: скорость dx по буквам (+ — вправо), dy по номерам (+ — вверх, к воротам Black), затем фаза (1 — мяч пропускает ближайший End Turn) |
| `t:` | кто последним касался мяча; `p` — умышленным пасом (нужно для правила о пасе своему вратарю) |
| `a:` | чья атака продолжается при свободном мяче, если последнее касание сделал соперник; выводится только при отличии от `t:` |

Пример: `b 37 1-0 f10/f11 e12 d14/d16 h12 f8 c7/b6 g6 j3 @e7,+1,-2,1 t:Wp` — ход Black, 37 полуходов, 1:0; W1 на f10 и бежит вниз, к своим воротам (был на f11), мяч катится из e7 на 1 клетку вправо и 2 вниз за шаг, шаг через один End Turn, последним мяча касался пасом White.

**Позиция внутри хода** (07.11.2026). Поля игроков всегда дают позиции на начало хода; что изменилось с начала хода, записывают необязательные поля после `t:`/`a:` (на начало хода их нет, и такая позиция пишется как раньше):

| Поле | Смысл |
| --- | --- |
| `m:W1g12,W3e7` | эти игроки уже ходили в этом ходу и стоят на указанных клетках; `W2e5!` — смещён, не ходив |
| `x:B2+1-1` | игрок уже атаковал в этом ходу, направление атаки dx, dy (в записи клеток) |
| `f:p`, `f:c`, `f:pc` | мяч в этом ходу уже сыгран (пас или удар); случилось случайное событие (ход нельзя отменить) |
| `l:0`, `l:1` | расстановка после рестарта, шаг расстановки |
| `s:a,b` | история запирания мяча белых и чёрных (биты трёх последних ходов), если не нулевая |

Владелец мяча стоит на своей текущей клетке (из `m:`, если он ходил). Свободный мяч может лежать на клетке игрока: пас пролетает над ним, рикошет падает на его клетку — движок создаёт такие состояния, и позиция читается так, как записана. Проверка — `TestPositionInsideTurn` (запись и чтение совпадают на всех состояниях случайной игры, внутри хода тоже, с теми же законными действиями).

Пример: `w 10 0-0 f11 d11 h11 f7 f12 i12 c12 f16 @W2 t:W m:W1g12 f:p` — ход белых, W1 уже сходил с f11 на g12, мяч в этом ходу уже сыгран.

Не записывается: отложенный рестарт после того, как вратарь взял мяч (`keeperRestartTeam`, `keeperBackPass`) — он разрешается в том же действии.

## Партия

Заголовок из тегов `[Имя "значение"]`, затем по строке на ход:

```
[Event "selfplay"]
[Date "2026.10.15"]
[White "full search, depth 1"]
[Black "full search, depth 1"]
[Seed "3"]
[Result "*"]

L. W 1f10 2c8 3i8 4f4
L. B 1f12 2i12 3c12 4f16
1. W 1e11 2b9 3h9 4e5
2. B 2h13 1x{won} 1f11 3b13 4e17
3. W 2a11 3f10 3x{kept} 4e7
4. B 1g10 2f15 3a15 4c19
```

| Элемент | Смысл |
| --- | --- |
| `L. W` | расстановка команды |
| `12. B` | ход в игре; номер — полуход матча (1…180), буква — команда |

В обсуждении с пользователем ходы нумеруются целыми, как в шахматах (решение 29.10.2026): полуход h записи — это ход ⌈h/2⌉ с указанием стороны (`30. B` — ход 15, чёрные). Формат записи пока не меняется.
| `; ...` | комментарий до конца строки; при записи так отмечаются голы, сейвы, перерыв, конец матча |

Теги: `Event`, `Date`, `White`, `Black`, `Seed` (зерно генератора), `Result` (`2-1` или `*`, если партия не закончена), `Position` (начальная позиция, если партия начинается не с расстановки).

Удар завершает ход, поэтому строка с ударом кончается на `#{...}` без End Turn. Ход, прерванный рестартом (гол, сейв, мяч у вратаря после паса или атаки), тоже кончается без End Turn — следующая строка начинается с расстановки.

## Программный интерфейс

| Функция | Что делает |
| --- | --- |
| `CellName`, `ParseCell`, `PlayerName`, `ParsePlayer` | клетки и игроки |
| `FormatAction`, `ParseAction` | действие (по состоянию до него: нужна команда и фаза) |
| `FormatOutcome`, `ParseOutcome` | исход |
| `FormatPosition`, `ParsePosition` | позиция |
| `GameRecord`, `WriteRecord`, `ReadRecord`, `ReplayRecord` | партия: запись, чтение с проигрыванием, повтор |

Для записи партии из программы: применять действия через `Apply(s, a, events, &outcome)` и складывать пары (действие, исход) в `GameRecord::actions`.
